# 🤔 Decision Maker

> Can't decide? Stop overthinking — type your options, spin the wheel, and let fate pick.

A tiny one-page web app that ends indecision in seconds. Enter any list of
choices ("Pizza / Sushi / Tacos"), hit **PICK FOR ME**, and the wheel of fate
spins dramatically before crowning a winner.

## ✨ Features

- 🎲 One-click random decision with a satisfying spin animation
- 📝 Any options, one per line — duplicates auto-removed
- 🏆 Bold winner reveal + a running history of past verdicts
- 🖤 Sleek dark card UI (no dependencies, no build step)

## 🚀 Run it in 30 seconds

1. Download or clone this repo.
2. Open `index.html` in any browser. That's it.

No installs, no servers — just double-click.

## 🧠 What I practiced

- DOM manipulation and event listeners
- CSS transitions for the spin animation
- Parsing and sanitizing user input
- `setTimeout` synced with an animation
